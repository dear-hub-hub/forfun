# AMPLIA Lab website

A responsive static homepage starter for GitHub Pages. It preserves the existing lab's core message and links to the original pages while presenting a more editorial, research-focused design.

## Publish with GitHub Pages

1. Create an empty GitHub repository, for example `amplia-lab`.
2. Upload these three files to the repository root and commit them.
3. In GitHub, open **Settings → Pages** and select **Deploy from a branch**.
4. Choose `main` and `/ (root)`, then save. Your site will be available at `https://<account>.github.io/amplia-lab/`.

## Before launch

Replace the text-only `JJ` profile circle with a licensed professor photograph, and update the selected-news and publication entries from the original Google Site. The original information architecture is linked throughout this first version so no content is hidden during migration.
